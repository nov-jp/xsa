XSA は EXtended Style Attribute の略称で、限界突破した style属性 を意味します。HTML の style属性 に、CSS の属性セレクタとカスタムプロパティを組み合わせた、シンプルなメタ・フレームワークです。

CSSプロパティ名 をベースとして、クエリとセレクタをエンコードした XSAプレフィックス に、ハイフン2つを先頭と末尾に追加してカスタムプロパティ化した XSAプロパティ、そして、それと対になる XSAルールセット によって、

HTML の style属性 から、子孫要素と擬似要素のスタイリング、クエリと擬似クラスによる条件分岐を可能にするスタイリング・インフラを構築します。

XSA は、XSAプロパティ の命名規則、XSAプロパティ と対になる XSAルールセット、XSAルールセット をまとめた CSSライブラリ、XSAルールセット を生成するスクリプトを包括的に扱っています。詳細は、XSA の GitHubリポジトリ と各種パッケージをご覧ください。

  • XSA
  • XSA CSS: XSAプロパティ と対になるルールセットの CSSライブラリ。
  • XSA JS: クライアントサイドで XSAプロパティ からルールセットを生成するスクリプト。
  • XSA PostCSS: ビルド環境で XSAプロパティ からルールセットを生成するツールセット。
  • XSA PHP: サーバサイドで XSAプロパティ からルールセットを生成するヘルパークラス。

Tailwind CSS と比較した例を挙げましたが、XSA はユーティリティファーストを推奨している訳ではありません。どういった情報を HTML に持たせるか、どのように運用するかは、使用する人次第です。

XSA の客観的な評価や、使用することで何がどう変わるかが知りたい場合は、ChatGPT や Google Gemini に次の質問をしてみてください。

このマニュアルは HTMLファイル です。XSA を使用して作られた、生きたマニュアルになっています。XSA がどのような意図を持って開発されたのか、XSA でどのようなことが可能になるのかを、すぐに使える HTMLコード やデモンストレーションを交えて紹介しています。
